# יצירת בחנים וכרטיסיות זיכרון ב-NotebookLM

## למה הסקיל הזה עובד דרך הדפדפן — ואסור להחליף ל-MCP

**`generate_quiz` דרך MCP מייצר בחנים באנגלית.** זה נבדק שוב ושוב.

שפת התוצר ב-NotebookLM נקבעת לפי **פרמטר**, לא לפי הוראה בטקסט. בדיאלוג של הדפדפן יש **בורר שפה** שאפשר לבחור בו עברית — וזו הסיבה היחידה שהמסלול הזה קיים. הוא לא מעקף מיותר ולא שריד מיושן.

### אזהרה — טעות שחוזרת

סוכן שעובד לפי הסקיל הזה נוטה לגלות באמצע ש"יש כלי `generate_quiz` ישיר שחוסך את כל המאבק בדפדפן", ולעבור אליו. **אל תעשה את זה.** התוצאה: בחן מהיר יותר, באנגלית, שהמשתמש לא יכול להשתמש בו.

מותר לשקול מחדש **רק** אם `generate_quiz` מקבל פרמטר שפה **ואימתת בפועל** שהתוצר יצא בעברית. עד אז — דפדפן.

### כרטיסיות זה סיפור אחר
`generate_flashcards` **כן** נעשה דרך MCP, עם פרמטר שפה מפורש. ראה `notebooklm-flashcards`.

---

## מה הסקיל הזה עושה

מנתח את מקורות הנוטבוק → מחלק לנושאים → מכין רשימת מושגים לכל נושא → יוצר בוחן ממוקד לכל נושא דרך הדפדפן → יוצר כרטיסיות זיכרון לכל נושא דרך MCP.

הרעיון המרכזי: בוחן אחד על 20 מקורות הוא כללי ולא יעיל. שלושה בחנים ממוקדים, כל אחד עם רשימת מושגים ספציפית — הרבה יותר ערך לימודי.

## כלים נדרשים

- `notebooklm:list_sources` — קריאת רשימת המקורות
- `notebooklm:generate_flashcards` + `notebooklm:check_job` — יצירת כרטיסיות
- `mcp__Claude_in_Chrome__*` — יצירת בחנים דרך הדפדפן (חובה לבחנים)

---

## עקרונות קריטיים — קרא לפני כל דבר אחר

### כלל 1: בחרת source_ids ממוקדים לכל נושא — חובה
כשיש מספר נושאים — כל בחן וכל set כרטיסיות מקבלים רק את ה-source_ids הרלוונטיים לנושא שלהם.
generate_flashcards עם כל המקורות = כרטיסיות כלליות ומדוללות.
generate_flashcards עם מקורות ממוקדים = כרטיסיות ממוקדות שבוחנות את הנושא לעומק.

### כלל 2: שפה — פרמטר לכרטיסיות, בורר בדיאלוג לבחנים
**לכרטיסיות (MCP):** העבר `language="he"` כפרמטר. הוראה בטקסט לבדה **לא מספיקה** — זו הסיבה שסטים יצאו באנגלית בעבר.
**לבחנים (דפדפן):** ודא שבורר השפה בדיאלוג מוגדר לעברית, ושהפרומפט פותח ב"צור בוחן בעברית".
אי-הקפדה על שניהם = תוצר באנגלית.

### רשימת בדיקה לפני כל generate_flashcards
- [ ] בחרתי source_ids רלוונטיים בלבד לנושא הזה (לא כל המקורות)
- [ ] העברתי `language="he"` כפרמטר ל-generate_flashcards (לא רק בטקסט)
- [ ] הפרומפט לכרטיסיות כולל את רשימת המושגים הספציפית לנושא

## שלב 0: ניתוח מקורות וחלוקה לנושאים

קרא את רשימת המקורות:

    notebooklm:list_sources(notebook_id="[ה-ID]")

נתח את הכותרות ותוכן המקורות. חלק אותם לנושאים לוגיים — בדרך כלל 2–5 נושאים.

לכל נושא הכן:

1. שם הנושא (קצר וברור)
2. source_ids רלוונטיים — רק המקורות שעוסקים בנושא הזה
3. רשימת 10–20 מושגים מרכזיים שחייבים להיבדק

### איך בונים רשימת מושגים?

עבור כל נושא, זהה:
- מונחים מקצועיים (שמות לטיניים, ראשי תיבות, שמות של תהליכים)
- הבחנות מרכזיות ("ההבדל בין X ל-Y")
- יחסים מרכזיים ("X גורם ל-Y", "X מחייב Y")
- עובדות מפתח (מספרים, שיעורים, גיאוגרפיה)

דוגמה — נושא "עופות ונדידה":
> עופות יציבים, חורפים, מקייצים, חולפים, מזדמנים, טרמיקות, נדידת יום, נדידת לילה, Remex, קיל (Carina), Cervidae, Bovidae, יעל נובי, מיליארד עופות, שדה מגנטי

### שלב 3 — פתח את דיאלוג ההתאמה האישית של הבוחן

    find: "התאמה אישית של הבוחן"
    → לחץ על הכפתור שנמצא (ref_XXX)
    → screenshot לאימות שהדיאלוג נפתח

אם לא נמצא הכפתור:
- הדיאלוג "יצירת דוח" עלול להיות פתוח — סגור (Escape)
- נסה `find: "בוחן button"` → לחץ "בוחן" → אז "התאמה אישית של הבוחן"

חשוב: הכפתור "דוחות" נמצא בסמוך — אל תתבלבל.

רמת קושי (ברירת מחדל: בינונית — שנה רק אם התבקשת):

### שלב 5 — כתוב פרומפט ממוקד עם רשימת מושגים

הסיבה שפרומפט ממוקד חשוב: NotebookLM ידגיש את המושגים שציינת ויצור שאלות על ה-edges הנכונים, במקום לסרוק כל המקורות באופן שטחי.

    find: "text input מה יהיה הנושא quiz topic textbox"
    → left_click על תיבת הטקסט
    → type: [הפרומפט]

#### תבנית פרומפט ממוקד:

    צור בוחן ב[שפה] ל[קהל יעד] על הנושא: "[שם הנושא]".
    
    המושגים שחובה לכלול בשאלות: [רשימת המושגים שהכנת בשלב 0].
    
    סוגי שאלות: הבנה מושגית, זיהוי בשטח, ויישום מעשי — לא רק שינון.
    כלול שאלות מסוג "כיצד תזהה...", "מה ההבדל בין...", "מדוע...".
    
    הבוחן מיועד לרמת [רמת הקהל].

#### דוגמה לנושא "שמירת טבע ומתודולוגיית הדרכה":

> "צור בוחן בעברית לתלמידי קורס מורי דרך ברמה בינונית על הנושא: שמירת טבע ומתודולוגיית הדרכה.
> המושגים שחובה לכלול: IUCN, Least Concern, Critically Endangered, גן מקלט, Pancratium maritimum, שגריר טבע, מעגל אוריינטציה, תכנון נתיב, הלימה לקהל, ניהול אינצידנטים, take-home message.
> סוגי שאלות: הבנה מושגית, יישום בשטח, ומקרי החלטה. כלול שאלות מסוג 'מה תעשה כאשר...'.
> הבוחן מיועד לרמת בינונית."

## שלב 7: יצירת כרטיסיות זיכרון (Flashcards) לכל נושא

לאחר יצירת הבחנים — צור כרטיסיות דרך MCP (ללא צורך בדפדפן). הפעל את כל הנושאים במקביל כדי לחסוך זמן.

שים לב: source_ids לכל נושא = רק המקורות הרלוונטיים לנושא הזה (לא כל המקורות).

    job_1 = notebooklm:generate_flashcards(
      notebook_id="[ה-ID]",
      source_ids=["id_מקור_נושא_1_בלבד", "id_מקור_נושא_1_נוסף"],
      language="he",          # ← חובה. בלי זה הכרטיסיות יוצאות באנגלית.
      instructions="צור כרטיסיות זיכרון בעברית בלבד. פן הכרטיסייה: מושג/מונח קצר. גב הכרטיסייה: הגדרה + דוגמה קצרה מהחומר. כלול את המושגים: [רשימת מושגים נושא 1]. רמת הפירוט: בינונית."
    )

    job_2 = notebooklm:generate_flashcards(
      notebook_id="[ה-ID]",
      source_ids=["id_מקור_נושא_2_בלבד", "id_מקור_נושא_2_נוסף"],
      language="he",          # ← חובה. בלי זה הכרטיסיות יוצאות באנגלית.
      instructions="צור כרטיסיות זיכרון בעברית בלבד. פן הכרטיסייה: מושג/מונח קצר. גב הכרטיסייה: הגדרה + דוגמה קצרה מהחומר. כלול את המושגים: [רשימת מושגים נושא 2]. רמת הפירוט: בינונית."
    )

    # בדוק סטטוס כל 30 שניות עד שכל ה-jobs מוכנים:
    notebooklm:check_job(job_id=job_1["job_id"], notebook_id="[ה-ID]")
    notebooklm:check_job(job_id=job_2["job_id"], notebook_id="[ה-ID]")

## טיפול בשגיאות נפוצות

| בעיה | פתרון |
|------|--------|
| Chrome extension לא מחובר | בקש מהמשתמש לוודא שהתוסף פעיל ומחובר |
| נפתח דיאלוג "יצירת דוח" במקום הבוחן | סגור עם Escape, נסה find מחדש |
| כפתור "יצירה" לא מגיב | ודא שהפרומפט נכתב בתיבה, נסה לחיצה בקואורדינטות ישירות |
| generate_flashcards נכשל | ודא ש-source_ids נכונים ורלוונטיים לנושא; נסה עם מקורות אחרים |
| list_sources נכשל (אין notebook_id) | חלץ notebook_id מה-URL של הנוטבוק |
| הבוחן יצא כללי מדי | בדוק שהפרומפט כלל את רשימת המושגים הספציפית ואת שם הנושא |
| הכרטיסיות יצאו כלליות מדי | ודא שה-source_ids = מקורות ממוקדים לנושא, לא כל המקורות |

## תקלות ידועות — אל תחקור מחדש

| תופעה | הסיבה | מה לעשות |
|---|---|---|
| הקריאה הראשונה נכשלת ב-timeout | התנעה קרה — הדפדפן עולה, טוען פרופיל, מאמת מול גוגל | **נסה שוב פעם אחת.** השנייה כמעט תמיד עוברת |
| `list_notebooks` מחזיר `[]` פתאום | שתי שיחות פתוחות במקביל נלחמות על אותו פרופיל כרום | **שיחה אחת בכל פעם** מול נוטבוקLM |
| `ask_notebook`: "element is not visible" | דיאלוג פתוח מקריאה קודמת מכסה את תיבת הצ'אט | Escape, או התחל שיחה נקייה |
| `debug_screenshot` נכשל ב-EPERM | הכלי כותב לתיקיית העבודה, שהיא לפעמים תיקיית מערכת מוגנת | התעלם — כלי דיבוג, לא חוסם |
| הכותרת של התוצר באנגלית | NotebookLM מחולל שמות בעצמו ונוטה לאנגלית | שינוי ידני. אל תבזבז סבב על ניסוח |
